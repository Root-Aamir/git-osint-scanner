## Overview

Git OSINT Scanner is a cybersecurity and open-source intelligence project designed to analyze public GitHub profiles, repositories and developer activity. It helps learners and researchers understand how public information can be collected and reviewed from open GitHub data.

## Features

- Analyze public GitHub profiles
- Review public repository information
- Check developer activity signals
- Useful for OSINT learning
- Beginner friendly cybersecurity project
- Clean GitHub portfolio project
